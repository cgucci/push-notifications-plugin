# Minecraft Admin

Private Minecraft server monitoring for `mc.cgooch.org`.

- `apps/dashboard/` — Fastify, SQLite, authentication, Web Push, and the mobile web app.
- `plugins/server-dashboard/` — Paper telemetry plugin (Java 25, Gradle 9.7.1).
- `docs/` — product and UI specifications.

GitHub remote: https://github.com/cgucci/push-notifications-plugin

Implementation and end-to-end verification are in progress.
